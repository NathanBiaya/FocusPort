# FocusPort - Photography Portfolio Engine

FocusPort is a professional-grade Django application designed for photographers to manage and showcase their work through a clean, responsive interface.

## 🚀 Live Demo
Check out the live project here: [https://focusport.onrender.com](https://focusport.onrender.com)

## 🛠️ Tech Stack
- **Backend:** Python / Django
- **Database:** PostgreSQL (Production), SQLite (Development)
- **Media Hosting:** Cloudinary
- **Deployment:** Render
- **Styling:** Custom CSS with a focus on UI Consistency and "Total Concentration" principles.

## ✨ Key Features
- **Dynamic Gallery Filtering:** Custom views that filter images by specific collections.
- **Admin Dashboard:** Full CRUD (Create, Read, Update, Delete) capabilities for galleries and photos.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.

## ⚙️ Local Setup
1. Clone the repo: `git clone <your-repo-link>`
2. Install requirements: `pip install -r requirements.txt`
3. Run migrations: `python manage.py migrate`
4. Start the server: `python manage.py runserver`
